# Shop Warehouse API

## Installation

1. Install JDK 17 or newer.
2. Clone the repository:
   ```bash
   git clone https://github.com/ferdy211/shop-warehouse.git
   cd shop-warehouse
   ```
3. Run the application:
   ```bash
   ./mvnw spring-boot:run
   ```
   The API runs at `http://localhost:8080`.

## Postman Collection

The collection is in the `postman` directory: [postman/shop-warehouse.postman_collection.json](postman/shop-warehouse.postman_collection.json)
